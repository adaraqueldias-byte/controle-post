# 🕯️ Cozyconfortable

Estrutura de pastas para produção dos vídeos **cozy / ASMR** (lareira, chuva,
vento, página de livro). Serve como base organizada pra você exportar,
guardar clipes, sons e templates reutilizáveis.

## 📂 Organização das pastas

```
Cozyconfortable/
├── Videos_prontos/        # exporta TUDO aqui (vídeos finais prontos pra postar)
├── Clipes_banco_capcut/   # baixa os melhores clipes de lareira/chuva
├── Sons_ASMR/             # chuva, lareira, vento, página de livro
└── Templates/             # salva o projeto de 9s pra reusar
```

| Pasta | Pra que serve |
|-------|---------------|
| **Videos_prontos** | Saída final. Todo vídeo exportado vai pra cá, pronto pra postar. |
| **Clipes_banco_capcut** | Banco de clipes crus (lareira, chuva) baixados pra montar os vídeos no CapCut. |
| **Sons_ASMR** | Trilhas/ruídos ASMR: chuva, lareira, vento, página de livro. |
| **Templates** | Projeto base de 9s salvo pra reaproveitar em cada novo vídeo. |

## 🎬 Fluxo sugerido

1. Baixe clipes bons em **Clipes_banco_capcut** e sons em **Sons_ASMR**.
2. Abra o projeto de 9s em **Templates**.
3. Monte o vídeo, ajuste o som ASMR.
4. Exporte para **Videos_prontos** e poste.
